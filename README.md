# GitHub Linux Project

## 📌 Project Overview

This project is created to learn and demonstrate the basic concepts of **Linux, Git, and GitHub**.

The project focuses on using the Linux terminal, managing files and directories, tracking changes with Git, and collaborating with team members through GitHub.

## 🎯 Objectives

- Learn basic Linux commands.
- Understand Git and version control.
- Create and manage a GitHub repository.
- Learn how to clone, add, commit, and push files.
- Understand Git branches.
- Practice collaboration using Pull Requests.
- Learn how multiple developers can work on the same project.

## 🛠️ Technologies Used

- Linux
- Git
- GitHub
- SSH
